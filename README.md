# From Tap to Meal
## A synthetic analytics-engineering case study for Food4Education

This independent portfolio project uses only synthetic data and publicly available information.
It does not represent Food4Education's internal systems, schemas, data, incidents, or current performance.

### Demonstrated concepts
- Multi-source ingestion design into BigQuery
- dbt-style staging and serving models
- Metric grain and KPI governance
- Meal-flow reconciliation
- Data-quality testing
- PII minimisation / hashing at the analytics layer
- Monitoring and incident-oriented thinking
- Reusable country/partner-oriented architecture

### Synthetic domains
Tap2Eat transactions, meal production, deliveries/school receipt, school master data, and mobile-money payments.
